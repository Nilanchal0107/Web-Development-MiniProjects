This repository contains my solutions, projects, and notes from **Scrimba's Fullstack Web Development Path** — a massive, project-driven course designed to take you from absolute beginner to a hireable fullstack developer.

The course is taught by multiple industry instructors and covers the entire JavaScript ecosystem, including frontend, backend, databases, AI engineering, and modern frameworks.

---

# Course Information

* **Course:** Learn Fullstack Web Development
* **Platform:** Scrimba / YouTube / freeCodeCamp
* **CEO / Host:** Per Borgen (Scrimba)
* **Languages Covered:** HTML, CSS, JavaScript, TypeScript, SQL
* **Frameworks & Tools:** React, Node.js, Next.js, Git, Chrome Extensions
* **Topics:** DOM Manipulation, APIs, Async JS, Databases, AI Engineering, Testing, Rendering Strategies
